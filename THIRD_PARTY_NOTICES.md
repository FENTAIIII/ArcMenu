# Third-party notices

ArcMenu's single-space TextDisplay background calibration follows the rectangle
technique and calibration constants in FluxUI (`BukkitUIPool`, `UNIT_SQUARE_RECT`).
The broader ArcMenu document, interaction and session implementation is independently
written. No TrMenu source code is included.
